💻 WINDOWS'TAN (MAC OLMADAN) TESTFLIGHT'A YÜKLEME:

Fiziksel bir Mac bilgisayarınız yoksa paketin içine eklediğim hazır codemagic.yaml ve .github/workflows/ios-testflight.yml dosyalarıyla Windows üzerinden ücretsiz Bulut Mac (Cloud macOS) kullanarak oyunu doğrudan TestFlight'a gönderebilirsiniz:

  1. GitHub'a Yükle: İndirdiğiniz ZIP paketini Windows'ta bir GitHub deposuna (repository) yükleyin.
  2. App Store Connect API Anahtarı (.p8): Windows tarayıcınızdan App Store Connect → Users and Access → Integrations → App Store Connect API sekmesine girip Issuer ID, Key ID ve .p8 dosyasını indirin (Mac Keychain gerektirmez!).
  3. Codemagic (Ücretsiz 500 dk/ay M2 Mac): codemagic.io hesabınızı GitHub deponuza bağlayın; paketteki codemagic.yaml bulutta otomatik olarak Xcode kurulumunu, imzalamayı (Auto Code Signing) ve TestFlight yüklemesini tamamlar.
